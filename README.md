# Retail Store Sales Analysis Dashboard

## Project Overview
This project was completed as part of the CodeAlpha Data Analytics Internship. The dashboard analyzes retail sales data using Microsoft Power BI to identify sales trends and performance across categories, cities, and products.

## Tools Used
- Microsoft Power BI
- Retail Store Sales Dataset

## Dashboard Features
- **Total Revenue:** Displays overall sales revenue.
- **Category-wise Sales Analysis:** Compares sales across product categories.
- **Monthly Sales Trend:** Shows changes in sales over time.
- **City-wise Sales Analysis:** Compares sales across cities.
- **Product-wise Sales Analysis:** Identifies product sales performance.
- **Category Slicer:** Allows interactive filtering by category.
